Diretrizes de Conteúdo OBRIGATÓRIAS para este arquivo:
1. Apresente o conceito de estratégias de migração para a nuvem e por que as empresas precisam avaliar diferentes abordagens para diferentes cargas de trabalho.
2. Detalhe detalhadamente os **7 Rs da migração** cobrados na prova:
   - **Rehost (Lift-and-Shift):** Mover a aplicação para a nuvem sem fazer alterações (ex: migrar uma VM on-premises para uma EC2).
   - **Replatform (Lift-tinker-and-Shift):** Fazer otimizações mínimas sem mudar a arquitetura central (ex: migrar um banco de dados de uma EC2 para o Amazon RDS gerenciado).
   - **Refactor / Rarchitect:** Reimaginar a aplicação usando arquiteturas nativas da nuvem e serverless (ex: quebrar monoliths em microsserviços com Lambda).
   - **Repurchase (Drop-and-Shop):** Trocar a licença atual por um software como serviço (SaaS).
   - **Retain:** Manter a aplicação no ambiente on-premises por razões específicas (regulatórias, dependências críticas).
   - **Retire:** Aposentar ou desativar aplicações que não são mais necessárias.
   - **Relocate:** Mover infraestrutura de hipervisor para hipervisor sem redesenho (ex: VMware Cloud on AWS).
